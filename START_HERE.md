Get the SAT Prep Platform running on your machine!

## **Windows Users** 🪟

### Easiest Way: Double-Click
1. Open folder: `C:\development\claude\SATPreparation\SAT Training Prep\`
2. **Double-click** the file: `RUN_APP.bat`
3. Wait for the browser to open
4. Done! 🎉

### Or Use Terminal
```cmd
cd C:\development\claude\SATPreparation\SAT\ Training\ Prep
npm run dev
```

Then open: http://localhost:5173
